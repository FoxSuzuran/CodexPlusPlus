# 按钮错位与重复布局修复

## 依据与范围

基线为本地 `1cb33a693c94441829ded9d1e3757296f9452daf`，已包含上游 v1.9.0。修复前核对了上游：#2224 已在本地历史中；#2462 已撤回且没有稳定复现依据，因此只借鉴观察宿主的方向；脚本市场 #44 早期底部挂载修复已在当前 Bennett 版本中，但未覆盖新版导航结构。

只读现场确认 API 组件被挂在 `data-app-action-sidebar-project-row` 的悬浮操作区，左边界超过侧栏，底部超出视口。三段约十秒的 CPU 采样中，对话对齐累计调用分别约 333、312、306ms；目标定位占大部分。一次长任务达到 311ms。页面当时仍在输出，这些样本不构成冻结工作负载的对照，也不能证明某个模块承担全部卡顿。

## 实现

- Bennett 改为明确的新版底部导航区域或旧版设置/设备控制栏，清理仍连接着 DOM 的错误旧挂载，不再猜测项目行和浮动位置。
- 对话正文优先使用原生 data 锚点，保留旧版及宽度变量回退。ResizeObserver 只观察布局宿主，替换目标时恢复旧样式并撤销过期观察；不观察自己改宽度的正文和输入容器。
- 对齐触发合并为两帧，单次显式请求最多四帧，执行期间不延长当前批次。忽略正文内部流式更新、纯文本和扩展节点变动；后台暂停，回前台恢复。异常释放调度状态并上报，关闭功能和重复注入会清理监听及任务。
- 后端配置未变化的心跳不重建菜单和效果；后端状态不变时不重复刷新速度控件。通用 DOM 扫描在已有待执行工作时不重复分类。
- DreamSkin 在本地生成适配层优化 `:has(*)`，直接收集非叶子元素；其余后代分支共用已访问祖先集合。保留匹配、过期标记移除和无变化不写属性，未修改上游皮肤子模块，运行时修订为 `28-ui-performance`。
- Daily 先过滤普通文本的 JSON 解析尝试，共用单条消息中的嵌套解码，原生用量通知不扫描工具调用；保留历史累计与实时差值。

扩展公开类名、constants、路由白名单和写权限保持原有接口。广告剥离、Plan、Daybreak、速度档位、粘贴和原生浏览器修复均保留。没有更改真实账户配置和统计数据。

## 验证与交付

新增 Bennett 挂载、侧栏重建、紧凑按钮、统计解码、布局批次和皮肤线性扫描回归。原脚本能使新增问题回归失败，候选脚本通过；两个补丁有明确原件哈希及逐字节应用校验，见 `patches/ui-user-script-fixes.md`。

使用现有依赖、原 target、固定 release 配置和 target/temp；不运行 Bash、不创建额外版本 EXE 副本，不替换已安装主程序。最终构建及测试结果记录在固定发布目录 `dist/windows/latest/manifest.json`。

验证通过：前端 711 项通过、1 项原有跳过；TypeScript 通过；注入测试 54 项通过；已安装用户脚本 37 项通过；后台恢复专项 9 项通过；Rust assets 6 项与注入桥接 60 项通过，测试单线程执行。真实 Edge 的旧侧栏布局回归覆盖六种缩放/RTL/变换场景；新增浏览器回归覆盖三种缩放下的 API/官方额度、DOM 重建和缺失宿主，以及四种窗口宽度下的正文/输入框几何、稳定写入与清理。

Rust 专项命令使用 `cargo test --release --locked --offline` 和既有 `.cargo/windows-release.toml`，复用 release 目录，不创建 debug profile。浏览器回归使用应用附带的 Playwright 和本机 Edge，没有安装依赖或操作正在运行的 Codex 页面。

安装时完整退出 Codex++ 托盘及 Codex，再替换已安装目录的 `codex-plus-plus.exe` 并重启。用户脚本补丁在磁盘应用，不清空配置；当前窗口是否已经加载新内容需以重载后的运行时为准。

安装后的验收应包括：首页及长会话、滚动项目列表、切换会话、侧栏折叠/展开、改变窗口宽度、额度与模型档位交替切换、后台再恢复。用三次相同场景采样比较长任务、定时器延迟和扫描栈；本次离线回归不替代安装后长期性能验收。
