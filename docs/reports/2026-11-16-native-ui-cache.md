# 原生界面预载调查与样式索引缓存

本轮把内存用于原生 CSS 的规则索引：新增懒加载样式时，复用旧规则的索引，只分析新增资源，并删除被新资源覆盖的旧重复规则。没有增加聊天历史请求，也没有额外挂载隐藏聊天页面。

## 调查范围与预载判断

- 已检查上游 `BigPizzaV3/CodexPlusPlus#3008`，其主题结构规则优化已包含在当前分支中。另检查 `openai/codex#59860`、`#33996`、`#29590` 的现有记录。这些报告提供排查方向，不能代替本机测量。
- 本机此前一次聊天点击的记录中，事件持续约 1728 ms，点击处理约 1008 ms，其中五次样式重算合计约 384 ms。原生 React 调度栈中包含同步样式工作；这个采样同时受追踪和编译竞争影响，不用作本轮性能对照。
- 当前原生页面约有 5500 个 DOM 节点、61 条侧栏会话行，JS 堆约 525 MiB。界面已有不少缓存，尚没有证据证明额外整页预挂载能解决当前样式瓶颈。
- 原生页签管理器已经在空闲回调中调度 `pinned-tab-preload`：只对提供兼容 `durableRoute.preload` 的页签恢复器调用，带版本、账号/host/thread 身份、断连和卸载检查。它不是一个可以无条件对任意侧栏聊天调用的预渲染入口。本轮没有绕开这些检查叠加另一套隐藏页面。
- 从当前实际加载的原生代码确认：`prefetchSharedThreadTurns` 只允许 `durable` host，最多保留十份、有效期一分钟，已有自动化列表调用；消费时还会校验页参数和结果。它不能直接用于本地 `local` 会话。未把 `resumeConversation` 或完整历史加载伪装成只读预取，避免额外接管和历史水合。
- 查询缓存中可见会话附件、列表等数据，但本地聊天历史有独立的原生管理器和分页链路。没有复制历史到另一份 ++ 缓存，以免引入失效和一致性问题。
- 当前运行及安装的 Codex++ 为 2.6.2；本轮源码为 2.6.10。检查到编辑框有草稿，因此只读取界面元数据和样式，没有切换当前聊天、输入或发送消息。Playwright 调试会话已经断开。

## 本轮改动

修改 `assets/inject/renderer-inject/11-native-style-cache.js`，并重新组装 renderer 注入产物。

原去重器在任何原生样式表集合变化后，都会重新插回已删除的重复规则，再序列化、索引所有原生规则。本机运行中的计数为九轮、累计约 1574 ms；这不是每次点击的开销。

新去重器保留按完整 CSS 文本和层叠上下文建立的规则索引。如果样式表只有尾部追加，旧表的身份、顺序、禁用状态、media 和 title 都没有改变，就只索引新增表。新增规则覆盖旧规则时，仅在涉及的旧规则容器中定位并删除对应规则，不重插其他旧规则。内存占用随当前加载的样式规则数量增长，清理时释放索引。

卸载、替换、重排、禁用、media/title 改变仍走完整恢复和重算。匿名 layer、嵌套声明及不支持的分组保留原有跳过逻辑；重复规则仍保留最后一条。清理按删除操作的逆序恢复原始规则。沿用原生静态资源不可变的既有假设，没有扩大到扩展样式或缓存 DOM 节点。

## 独立浏览器对照

从本机正在运行的原生页面只读导出 49 份原生 CSSOM，合计 2,654,735 字节。这份快照已经经过旧去重器处理，不能代表原始安装包的全部重复规则。将同一份快照在独立 Edge 页面逐份加载，对照旧、新、新、旧四轮；每轮全新浏览器上下文，收集去重器自身耗时，强制 GC 后读取 JS 堆，并校验清理后规则顺序完全恢复。

| 指标 | 原实现，两轮 | 新实现，两轮 |
| --- | --- | --- |
| 49 份 CSS 累计缓存处理时间 | 2979.3 / 2921.4 ms | 100.3 / 93.6 ms |
| 均值 | 2950.4 ms | 97.0 ms |
| 最大单轮处理时间 | 74.1 / 87.5 ms | 67.2 / 60.5 ms |
| GC 后新增保留 JS 堆均值 | 4.18 MiB | 7.64 MiB |

这个受控顺序加载条件下，累计处理耗时下降约 96.7%，额外保留 JS 堆约 3.46 MiB。首次完整索引仍然存在，改动不保证最大单次阻塞同比下降。若多个资源在一次刷新前同时到达，原实现也只扫描一轮，收益会小于上述逐份加载对照。**这些数据不等于真实聊天切换耗时，也不表示切换快了三十倍。**

对照只在独立页面回放样式，没有把草稿或聊天正文导出为浏览器测试数据。证据位于仓库 `target/temp/native-ui-preload-20261116`，包括原生样式快照、缓存元数据、对照脚本及 `native-cache-benchmark.json`。指标字段随后由 `visited` 改名为 `indexed`，以明确它只统计索引遍历，不把旧容器定位扫描算成新增规则分析；算法不变。
