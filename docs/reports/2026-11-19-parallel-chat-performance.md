# Codex++ 并行对话与界面卡顿排查

在 Windows 上对运行中的 Codex renderer 采集 16.1 秒 CPU 与时间线。旧安装包产生 43 次超过 50 毫秒的主线程任务，最长约 402 毫秒，样式重算累计约 8.0 秒。主要调用栈经过滚动容器定位，还有每日用量浮层、用量角标与请求状态的开销。旧包仍在运行，发布包中的滚动修复通过了浏览器对照。

| 路径 | 修改与验证 |
| --- | --- |
| 阅读位置与切换 | 延续活动页内的滚动定位。40 批并行内容更新的浏览器对照中，滚动容器宽度读取从 80 次降到 0，切换和重建仍能恢复阅读位置。 |
| 模型菜单 | 关闭时停止全页轮询，菜单挂载或变更时重扫。三条模拟输出期间全页查询从 4 次降到 0 次，实际点击可重新打开并完成分组。 |
| 请求状态与用量 | 状态跟随活动会话。只有后台请求时跳过输入框几何读取。用量角标重复渲染 40 次，DOM 写入从 120 次降到 0 次，切回保留原角标。 |
| 每日用量浮层 | 避让与工具扫描按相关 DOM 变更触发，工具卡片按其活动会话归属。将两版判断用于同一批实机变更时，避让调度从 22 次降到 4 次，工具扫描调度从 53 次降到 0 次。真实工具卡挂载仍触发统计。 |
| 彩虹侧栏 | 两条实机会话运行期间，暂停彩虹滤镜把 GPU 进程 CPU 时间从每秒 1,193–1,269 毫秒降到 672–735 毫秒。候选样式在阅读时显示静态渐变，悬停和键盘聚焦时播放一轮，实机短时替换确认持续动画停止。 |
| 常驻管理器 | 吸纳上游 #3167 的 Agent 命令索引，共用网关轮询和同一份读结果。隔离的新旧原生管理器中，网关读取中位数从 241.6 毫秒降到 43.3 毫秒。Windows WebView2 的文档在窗口收起后仍报告可见，定时读取增加原生窗口检查。11.5 秒托盘观测中，网关轮询从 2 次降到 0 次。 |

前端测试 2,444 项通过，2 项沿用跳过。相关 Rust 测试 263 项、模型菜单浏览器测试 23 项、每日用量采集测试 22 项通过。Windows 单应用发布包完成嵌入资源核验。

每日用量和彩虹侧栏为独立的市场脚本补丁，见 [每日用量补丁](../../patches/daily-token-parallel-conversations.md) 和 [彩虹侧栏补丁](../../patches/rainbow-sidebar-interaction-motion.md)。采样与构建记录保存于 `target/temp/interaction-performance-20261119/`。旧安装的完整会话继续运行，界面切换的新版实机耗时仍待安装后测量。
