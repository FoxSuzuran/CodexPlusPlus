### 设置读取

`pet_real_mouse_enabled` 在桌宠关闭时仍每 500 毫秒调用完整的 `SettingsStore::load`。完整读取会对全部供应商配置做 TOML 归一化，而这里仅使用增强总开关与鼠标跟随开关。

抽出内部 `load_parsed`，供两处鼠标驱动检查使用。保留 JSON 全量类型校验、16 MiB 读取上限、版本计算、旧设置迁移、缺失文件默认值和错误处理。对外的 `load` 仍执行原有归一化与嵌套调用保护；两个开关仍以原有频率读取，没有增加设置生效延迟。

### 本机 HTTP

CDP 的 `/json`、`/json/version` 和桥接 `/proxy-status` 都访问固定回环 HTTP 地址。原客户端创建过程仍加载 Windows TLS 根证书。

这三处改用同一个内部构造函数，关闭系统代理和内置 TLS 根证书加载，保持原有请求超时。供应商、更新下载及其他 HTTPS 客户端不经过这个函数。

### 状态栏定位

用量状态栏原来在每次相关 MutationObserver 回调中立即读取布局。现在同一帧合并定位，停用时取消待执行帧，并检查运行状态，防止卸载后重新挂载。现代和旧版 composer 的选择器、会话归属规则保持原有行为。

`statusline-browser-comparison.json` 记录：原逻辑在帧前定位 20 次，修改后帧前为 0、下一帧为 1；有待执行任务时卸载，定位次数保持为 1。
