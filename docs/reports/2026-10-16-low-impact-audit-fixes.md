# 低侵入审计优化

源码基线：`a75ce8b0eb732aa49b18d576107a080257295d60`。保留现有 Rust / React 分层、目录、设置协议和扩展接口，没有增加依赖或拆分应用。

## 修复范围

| 项目 | 本次处理 |
| --- | --- |
| 设置保存失败丢草稿 | 只在保存成功后更新已保存基线；失败保留当前编辑，保存期间的新编辑也不会被旧响应覆盖。 |
| 离开页面覆盖未保存设置 | 复用现有未保存提示的外观，提供保存并继续、放弃、取消；覆盖页面导航、工具切换、外部管理页跳转和管理器退出。刷新设置也保留当前草稿。 |
| 会话翻页响应倒序 | 请求序号只允许最新响应写入列表；旧空页响应不能触发回退翻页。 |
| 隐藏窗口仍频繁轮询 | 外部导入与主题链接采用串行轮询：可见 1.2 秒、隐藏 30 秒，恢复可见或聚焦时立即检查，卸载时清理。 |
| 浮动面板全量扫描 | 忽略扩展自身及无关 DOM 变化；隐藏时停止扫描，恢复后扫描一次；按 turn key 选择最新挂载轮次后才提取文本，保留虚拟列表的最新轮次锚点。运行时版本升为 2.0.9。 |
| 删除大会话阻塞与内存复制 | Tauri 命令沿用 `spawn_blocking`；备份 JSON 移入原备份结构，删除阶段仅保留路径，不再复制整份 rollout 数据。备份、回滚、不可读文件的失败语义不变。 |
| Skills 网络等待无界 | Skills 专用客户端连接超时 10 秒、请求 30 秒、压缩包 120 秒；单仓库目录刷新总时限 60 秒，沿用已有错误提示与缓存回退。其他 API 客户端不变。 |
| 用量栏切换闪烁 | 内存缓存最多 32 个会话的数据，切换时立即渲染对应读数或占位符；每次重新获取 DOM，旧请求不会把读数画到另一会话。 |
| 扩展页面遮挡原生返回与菜单 | 吸纳上游 #2553；覆盖页可使用原生 Back 返回，菜单位于页面上层。返回按钮属性保存在节点上，DOM 重建后重新获取，不缓存 DOM 引用。 |
| 会话搜索与多选含义不清 | 明示搜索只针对本页；分页显示页码和总会话数；增加取消全选、本页已选数量与复选框可访问名称。 |
| 确认对话框键盘支持 | 确认框和未保存提示默认聚焦取消，约束 Tab / Shift+Tab，Escape 取消，关闭后恢复仍存在的入口焦点。 |
| 更新显示模拟进度 | 吸纳上游 #2480；显示实际下载百分比，无总大小或写盘、启动安装器阶段使用不定进度；监听失败可退出等待状态并重试。 |
