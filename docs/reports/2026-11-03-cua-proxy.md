# 官方浏览器与 Computer Use 代理修复

日期：2026-11-03。基线：`de4d56de`，修复源码：`764003fe`。
仅处理官方 `cua_repl` 的浏览器和 Computer Use。

## 实现

新增独立代理适配，接入实际 launcher 会话的准备、正常停止、关闭增强和启动失败
清理流程。官方入口在原始 `launch()` 前加载初始化模块；权限预加载、认证、
trusted services、参数及原始错误处理不变。旧浏览器身份适配独立运行。

工具已有代理优先，其次是 Codex++ 调用方代理，最后是既有系统静态代理检测。
支持大小写，保留绕过列表并补齐本机回环。不固定端口、不改系统代理、不启用 TUN、
不设置 `NODE_USE_ENV_PROXY`。没有任何代理时保持原环境；探测失败报告问题并保留代理。

按当前插件元数据选择运行时；启动前准备，运行期间每两秒检查变化。代理变更在
下一次工具启动生效。原文和候选内容先落盘，恢复仅覆盖仍等于本次候选内容的文件。
异常退出下次启动恢复；外部修改或未知结构保留现场并拒绝覆盖。
详见 `docs/native-cua-proxy.md`。

修复前复核上游：官方 #42454、#53635 仍 open；以 CUA/proxy 查询两个项目的
相关 PR，未找到可直接吸纳的实现。没有向上游提交消息或 PR。
